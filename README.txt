HOW TO PREVIEW
1. Keep the folder structure unchanged.
2. Open index.html in a browser, or open the folder in Visual Studio Code and use Live Server.
3. Internet access is needed for the Google Fonts import. The rest of the page assets are local.

BEFORE PUBLISHING
- Confirm all company contact details and service descriptions.
- Replace the cropped reference hero image with an original, licensed, high-resolution image.
- Replace illustrative service/project panels with approved Northstream photos.
- Connect the inquiry form to a real email service or backend. The current form is demo-only and does not send data.
- Add real Privacy Policy and Terms pages, and test all links on mobile and desktop.
